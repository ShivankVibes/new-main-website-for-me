# Morse Translator

A quick little web app for translating text to Morse code and back again.

## What it does

Type in plain English text and it converts it to Morse code (dots and dashes), or paste in Morse code and get it converted back to readable text. Simple, no-frills, does exactly what it says.

## Why I built it

I wanted a small, self-contained project I could build in an evening — something with a clear input/output and no external dependencies. Morse code translation is a classic beginner-friendly project, but I wanted my version to actually look nice and feel smooth to use, not just be a plain textarea.

## Running it

Just open `morse-translator.html` in any browser. Everything runs client-side — no server, no API calls, no internet connection needed once the page is loaded.

## Possible future additions

- Audio playback of the Morse code (beeps timed to dots/dashes)
- Adjustable speed/WPM for playback
- Support for Morse code in other languages
