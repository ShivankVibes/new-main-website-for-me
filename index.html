Journey

My Story So Far

Every step has been a lesson.

  1. 2017 · Age 5

    Started Coding on Scratch 🐱

    At age 5, I started making games and animations on Scratch. Drag, drop, and watch things move — it was like magic. This is where the obsession started.

  2. 2020 · Age 8

    Levelled Up to Python 🐍

    Moved from blocks to real code. Python was my first text-based language — automation scripts, games with Pygame, and small tools. The transition clicked immediately.

  3. 2022 · Age 10

    HTML · CSS · JavaScript 🌐

    Discovered the web. Built my first real websites — learned how design and code come together. JavaScript opened up interactivity and I was hooked on front-end development.

  4. 2025 · Age 13

    Into Arduino & Hardware 🤖

    Entered the physical world — sensors, LEDs, circuits, and microcontrollers. Built the Electronic Tanpura. ESP32 and Raspberry Pi opened new possibilities.

  5. 2026 · Age 14

    3D Printing & Products 🖨️

    Got the Bambu Lab A1 + AMS Lite. Started turning digital designs into physical objects. Now shipping real client websites, multicolor prints, and sharing everything on YouTube.

  6. Now & Beyond

    Fluent in Most Languages 🚀

    From Scratch to systems programming — the journey continues. The goal: build real products that solve real problems, ship open source tools, and never stop learning.
