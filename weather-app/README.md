# Weather App

A simple static weather app that fetches real-time weather using the free Open-Meteo APIs.

## Features

- Search by city name
- Shows current temperature, wind, humidity, pressure, and condition
- Uses no API key
- Responsive and lightweight

## Run locally

1. Open `index.html` in your browser, or serve the folder with a static server.
2. Enter a city name and click **Get Weather**.

## Notes

This app uses:
- `https://geocoding-api.open-meteo.com/v1/search`
- `https://api.open-meteo.com/v1/forecast`

Both endpoints are free and do not require an API key.
